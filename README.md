# Smart-exam-allocator


 An AI-powered exam scheduling and classroom allocation system that automates timetable generation while eliminating conflicts in faculty, classrooms and student examinations.


# 📌 Problem Statement

Educational institutions spend significant time manually preparing examination schedules.

Manual scheduling often leads to:

- ❌ Faculty scheduling conflicts
- ❌ Classroom overlaps
- ❌ Double-booked examinations
- ❌ Uneven classroom utilization
- ❌ Last-minute modifications
- ❌ Human errors

Managing hundreds of students, multiple departments, and limited classrooms makes the process slow, inefficient, and error-prone.

---

# 💡 Solution

Smart Exam Allocator automates the complete examination scheduling process using intelligent conflict detection and optimized classroom allocation.

The system automatically:

- Generates exam schedules
- Allocates classrooms
- Checks faculty availability
- Detects scheduling conflicts
- Prevents overlapping exams
- Sends notifications
- Creates student-wise timetables

This significantly reduces manual effort while improving scheduling accuracy.

# ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/yourusername/smart-exam-allocator.git
```

Move into the project

```bash
cd smart-exam-allocator
```

Install dependencies

```bash
npm install
```

Run the application

```bash
npm start
```

Backend

```bash
npm run server
```
